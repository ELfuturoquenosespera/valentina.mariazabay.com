# Valentina · María Zabay

Versión estructurada de la página original, sin cambios de diseño ni de contenido.

## Organización

- `index.html`: contenido HTML.
- `css/styles.css`: hoja de estilos original, con los tres atributos de estilo puntuales trasladados aquí.
- `js/main.js`: JavaScript original del lector y del carrusel.
- `assets/images/`: imágenes originales extraídas de las cadenas Base64, sin recomprimir ni retocar. Las imágenes repetidas se guardan una sola vez.

## Uso

Abre `index.html` en un navegador. Para publicar en GitHub Pages, sube el contenido de esta carpeta a la raíz del repositorio, respetando las carpetas. No requiere compilación ni bibliotecas externas.

Se han conservado los enlaces, la composición SVG de la sección de la autora, el lector modal, la navegación y la visualización adaptable.
